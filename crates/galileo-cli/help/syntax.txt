Galileo language card: one example for each production of SPEC §9.4.
Each `== production` heading names the grammar rule; the lines under it are a
whole file that compiles. A `# file: NAME` line starts another module.
Templates are declared phrases, not English: a line must match exactly one.

## Rules

== rule
type Door, Hero
given {door: Door} is unlocked
derived {door: Door} opens for {hero: Hero}
rule unlocked-doors-open: ?door opens for ?hero
  when ?door is unlocked
  and ?hero is a Hero

== head
type North
derived for North
  menu-count: Int
rule menu-count: ?north.menu-count = ?count
  when ?north is a North
  and ?count = 0

== literal
type Hero, Key
given {hero: Hero} holds {key: Key}
given {hero: Hero} is banned
given {hero: Hero} has strength {n: Int}
derived {hero: Hero} is ready with {n: Int}
rule ready: ?hero is ready with ?total
  when ?hero holds ?key
  and not ?hero is banned
  and ?hero has strength ?s
  and ?s > 0
  and ?total = ?s + (count where ?hero holds ?k)
  and ?bonus in [1, 2]
  and ?bonus <= ?total

== aggregate
type Hero, Key
given {hero: Hero} holds {key: Key}
given {key: Key} weighs {n: Int}
derived for Hero
  carried: Int
  favourite: maybe Key
rule carried: ?hero.carried = sum ?w where ?hero holds ?k and ?k weighs ?w
  when ?hero is a Hero
rule favourite: ?hero.favourite = min ?k by ?w where ?hero holds ?k and ?k weighs ?w
  when ?hero is a Hero

== conj
type Hero, Key
given {hero: Hero} holds {key: Key}
given {key: Key} is shiny
derived for Hero
  shiny: Int
rule shiny: ?hero.shiny = count where ?hero holds ?k and ?k is shiny
  when ?hero is a Hero

## Requirements

== claim
type Hero, Room
state {hero: Hero} is in {room: Room}
  exactly one room per hero
state {hero: Hero} is armed
event move: {hero: Hero} moves to {room: Room}
Ash is a Hero
Hall is a Room
Vault is a Room
initially
  Ash is in Hall
requirements
  Ash is in Hall
  never Ash is in Vault
  always Ash is in Hall
  Ash is in Vault requires Ash is armed
  ?hero is in Vault only after ?hero is in Hall
  ?hero moves to Vault only when ?hero is armed

== quant
type Hero, Room

Ash is a Hero
Hall is a Room
Vault is a Room
Ash is in Hall
requirements
  some ?h: ?h is in Hall
  every ?h: ?h is a Hero
  no ?h where ?h is in Hall: ?h is in Vault

## Events and handlers

== handler
type Hero, Room
state {hero: Hero} is in {room: Room}
  exactly one room per hero
event move: {hero: Hero} moves to {room: Room}
on ?hero moves to ?there
  when ?hero is in ?here
  then ?hero is in ?there
  ensures
    ?hero is in ?there
  may skip

== post
type Hero
state entity Key
state {hero: Hero} holds {key: Key}
state {key: Key} lies here
event pick-up: {hero: Hero} picks up {key: Key}
event drop: {hero: Hero} drops {key: Key}
effect forge: {hero: Hero} forges
event smith: {hero: Hero} smiths
on ?hero picks up ?key
  when ?key lies here
  then not ?key lies here
  and ?hero holds ?key
on ?hero drops ?key
  when ?hero holds ?key
  then not ?key is a Key
  and ?hero forges
on ?hero smiths
  then ?new is a new Key
  and ?hero holds ?new
