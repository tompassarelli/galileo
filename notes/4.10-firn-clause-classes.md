## Classification boundary

Muove rows own facts, contracts, predicates and selected plans. TypeScript rows own external-format parsing, rendering, generic sequence/string operations and OS execution. Pure code is not automatically decision logic. Blank separator lines belong to the preceding definition; a range ends immediately before the next top-level definition. Counts include declarations, fields, bodies and blank lines. These are counts of source blocks assigned to a destination, not forecasts of emitted code size.

Dispatch token ambiguity, defaults, aliases, terminal errors and plan order stay in Muove. TypeScript supplies argv facts, renders diagnostic/help bytes and executes the ordered plan, stopping after the first nonzero status. Command summaries, usage and spacing remain metadata on command facts. Diagnostic and missing-leaf decisions retain status/descriptor and a reason; existing message templates move to the host. The host reconstructs the existing Plan/Diagnostic JSON envelope required by 4.11.

Prewarm repository candidate selection and priority stay in Muove; TypeScript supplies path components and encodes URIs/keys. Lease and process records are parsed in TypeScript; exact PID/argv comparisons and deduplicate/supersede/contend outcomes stay in Muove. Fixed argv constructors remain host mechanics and supply expected identity facts. stamp-current consumes the host-trimmed stamp, line-fires consumes parsed Git updates, and rebuild-argv consumes host-scanned suffixes. String/sequence helpers called from decision blocks are host preprocessing or lowering operations, not independent rule policy.

For host listing, listed-hosts becomes a decision over an observed directory: empty, error or inspect request. TypeScript executes inspect-entries and supplies stat observations to inspection-result. The 16384-entry bound, kind 2 inclusion and ENOENT treatment stay in Muove. handles is the exact argument acceptance query. Host formatting, sorting, errno text, bridge calls and output/status delivery stay in TypeScript. The host uses the existing bridges; no pin is changed.
